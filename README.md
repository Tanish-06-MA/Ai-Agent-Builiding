# 🤖 First AI Agent with Hugging Face SmolAgents

This is my first AI Agent built while learning the Hugging Face Agents Course.

## Features

- Built using Hugging Face SmolAgents
- Uses OpenRouter API for free LLM access
- Runs with CodeAgent
- Generates answers by reasoning and executing Python code
- Environment variables managed using python-dotenv

## Tech Stack

- Python
- Hugging Face SmolAgents
- OpenRouter API
- OpenAI Compatible API
- UV Package Manager
